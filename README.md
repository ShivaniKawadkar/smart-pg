# Smart PG Management System

Smart PG is a web-based PG, Hostel, Co-Living and Flat Finder application.

## Features

- Find PG, Hostel, Co-Living and Flat properties
- Search properties by location
- Filter by property type
- Filter by PG type
- Filter by food availability and food type
- Filter by maximum rent
- View property details
- Add new properties
- Edit and delete properties
- Location-based search
- Nearby property search
- Ratings and amenities information
